gaze-grid 0.4.0

- Add System keyboard input using the target application's Windows layout or the Linux portal injection device's XKB map. Labels follow supported modifiers and layouts without consuming pending dead keys.
- Preserve Personal English US as the default, with the same key positions, text, macros and navigation. Alphabet keys now declare their physical identities explicitly; older keyboard files remain compatible.
- Add experimental local scratchpad composition using an optional Qt Virtual Keyboard engine. The Windows installer bundles the engine, but ordinary startup does not activate it. Launch `gaze-grid.exe --local-ime`, select System under Keyboard source, then choose a language. Pinyin and Japanese Roman input, candidate paging, correction and cancellation have been validated. This route is separate from Windows native IMEs; other scripts need additional acceptance testing.
- Use a Qt text editor for scratchpad editing and composition. Keep IME input confined to the registered scratchpad, and reject stale candidate selections.
- Preserve stationary gaze dwell across candidate updates and defer candidate notifications to avoid reentering an engine during list updates.
- Add configurable keyboard transitions and mouse-click durations, and persist selected key/button modes. Enforce the requested minimum click duration even when a platform timer wakes early.
- Simplify settings titles and labels, move startup/sign-in settings under System, and use a color picker for scroll-zone colors.
- Add isolated local testing with a distinct application icon and opt-in native Windows layout acceptance tests. Fix Windows test discovery with MSVC's Qt meta-object compiler.

Windows x64 builds retain Tobii support and the existing GazeGrid signing identity.
Install the Tobii Experience software for your tracker; Tobii runtime DLLs are not
redistributed in the installer. The self-signed UIAccess build requires trusting
the included public certificate. Declining trust uses the unsigned fallback.
