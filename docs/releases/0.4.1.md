## Changes

- Add offline prediction models and a saved language selector for 18 languages. Chinese, Japanese, and Thai initially predict character clusters; Korean and the other languages use word tokens.
- Enable best-effort predictions in System mode, including conversation layouts. Suggestions use GazeGrid's typing history, which can differ from text edited externally or converted by an IME.
- Insert accepted Windows desktop suggestions as Unicode text, preserving accented and non-Latin characters across keyboard layouts.
- Show Caps Lock's active state using the locked-key indicator, including changes made with a physical Windows keyboard.
- Preserve the established English model under the consistent `eng-v1.bin` filename.

The optional local IME continues to show its conversion candidates. These prediction models do not add new gaze keyboard layouts or Windows TSF integration.
