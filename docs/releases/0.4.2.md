## Changes

- Add Dwell grace in gaze settings. Brief departures pause unfinished key dwell, returning within the grace period resumes it, and other keys begin dwelling immediately. The default is 0 ms, preserving existing behavior.
- Add Dual Bars and Opposing Bars dwell indicators.
- Add colorful keyboard themes with clearer two-word names.
- Add a prediction Unicode insertion setting and remove completion spaces before punctuation when enabled.
- Fix the settings dropdown click area.
- Prevent Windows cursor flicker during magnifier capture.
