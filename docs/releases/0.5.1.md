## Changes

- Use caret context for prediction and completion edits in the local scratchpad and supported Windows desktop controls, with surrounding-text support for Plasma input.
- Improve language-aware prediction, including Turkish casing, German capitalization and word forms, Vietnamese phrase completions, and supplementary Unicode letters.
- Add offline Chinese and Thai word segmentation and updated prediction models.
- Compose Korean Hangul and align prediction languages with the local input engine.
- Restore prediction after composition and preserve Windows startup registration during installer upgrades.
- Fix the Microsoft Windows SDK header dependency in UI Automation support.

Desktop completion depends on the target application's text and caret support; unsupported controls retain best-effort context.
