## Changes

- Restore prediction in VS Code and other Monaco editors when their accessibility provider exposes a notice instead of editor contents. Use the text GazeGrid types until reliable caret context is available.
- Keep UI Automation surrounding text inside the editor, excluding neighboring interface text.
- Add completion spaces before line breaks and preserve punctuation spacing at line ends.
- Add **Off** to **Live refresh**. Off takes one screenshot per target and stops background capture, independently of progressive zoom.
- Preserve the live refresh choice in saved preferences and shared sign-in settings.
- Reduce conversation keyboard loading by creating text editors only for scratchpad cells and avoiding redundant focus requests. Sign-in scratchpads retain both physical-keyboard and gaze typing.

When VS Code does not expose editor contents, predictions use GazeGrid's typed-text history. Enable **Editor: Accessibility Support** in VS Code for caret-aware context. External edits and caret movement can leave typed-text history out of sync.

The sign-in scratchpad and layout transitions pass automated UI tests. The reported pause on the actual Windows sign-in screen still needs a live retest.
