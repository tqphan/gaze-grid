## Changes

- Recognize empty text fields as valid caret positions, allowing sentence-starter suggestions in empty message boxes and native Windows editors.
- Refresh Windows caret snapshots so a temporary read failure cannot leave suggestions stuck blank, including when the message box already contains text.
- Avoid redundant caret reads during typing when the target context has not changed.
- Preserve the latest caret update while edits are queued. Private-field and selection checks remain in place.

Automated tests cover empty and nonempty message boxes, recovery after a failed caret read, and accepting a recovered suggestion with its trailing space. Live confirmation in the Codex and Claude message boxes is still pending.
