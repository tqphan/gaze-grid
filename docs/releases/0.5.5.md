## Changes

- Add **Best-effort only** under **Settings > Typing & speech > Word prediction**, enabled by default. Desktop prediction and completion use the keys GazeGrid sends, even when the target exposes text and caret context.
- Turn the setting off to use application text and caret context when available. Save preferences to retain the choice.
- Preserve private-field protection and scratchpad prediction.

Automated checks cover the default, saved preferences, completion from typed-key history, private fields, and caret-aware behavior when the setting is off.
