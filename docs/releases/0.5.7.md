## Changes

- Reject keyboard XML deeper than 64 levels or containing more than 50,000 elements to prevent resource exhaustion. The main keyboard silently keeps its current layout when loading fails.
- Check XML resource limits before opening layouts in the keyboard editor.
- Remove certificate trust added by the updated installer on uninstall, while preserving pre-existing trust. Certificate trust remains enabled by default for UIAccess keyboard functionality.
- Pin GitHub Actions to verified commit hashes and remove the release signing identity before uploading artifacts.

Validation covers XML limit boundaries, extreme nesting, bundled keyboard layouts, and keyboard editor behavior. Installer trust lifecycle checks are included in the Windows release workflow.
