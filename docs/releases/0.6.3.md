## Changes

- Add selectable Mill Mouse-style adaptive smoothing with Speed, Response, jitter, snap, and cursor-feedback settings.
- Add Edge retention and Center + edges assist modes while preserving the existing Center pull option and saved defaults.
- Add adjustable edge range and inset, and retain the new smoothing settings in saved and Windows sign-in preferences.
- Add regression coverage for smoothing formulas, tracking recovery, settings persistence, UI selectors, and all assist modes in absolute and relative movement.

The Mill Mouse option independently implements the recovered interpolation formulas and edge-retention principle. Its application-specific mode flags are not reproduced, so identical behavior in every mode is not established.
